# 스페셜 솔져

카툰풍 4대4 모바일 FPS 프로토타입. 브라우저(Three.js)에서 바로 실행됩니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 조작감 · 타격감 (터치 패드, 감도, 조준 보정, 흔들림/반동/진동) | ✅ |
| 2 | 무기 스펙 (5종, 반동 패턴, 탄속·낙차, 거리 감쇠, 사격 모드, 조준경) | ✅ |
| 3 | 맵 설계 (저격 라인 · 근접전 · 우회로, 엄폐물 높이, 시야선 분석) | ✅ |
| 4 | 캐릭터 · 클래스 (속도, 체력, 체형, 피격 판정, 패시브, 선택 화면) | ✅ |
| 5 | 게임 모드 (팀 데스매치 4대4, 저격전, 칼전, 칼칼전, AI, 리스폰 무적) | ✅ |
| 6 | 사운드 (3D 입체 음향, 발소리 사플, 가림·거리 감쇠, 단계별 재장전, 캐릭터 보이스) | ✅ |
| 7 | HUD · UX (미니맵, 스코어보드, 소리 방향 표시, 점프, HUD 편집기 2·3·4핑거) | ✅ |
| 8 | 육성 · 경제 (무기 등급·강화, 파츠 7종, 보급 상자, 일일 미션, 업적, 계정 레벨) | ✅ |

## 모바일에서 플레이
- 가로 모드로 접속 → 시작 화면 안내대로 **홈 화면에 추가**하면 주소창 없이 전체 화면·가로 고정 앱처럼 실행됩니다 (아이폰은 이 방법만 전체 화면 가능).
- 화면 오른쪽 위 **☰** 하나에 병영 · 모드 · 캐릭터 · 맵 · 설정 · HUD 편집 · 전체 화면이 모여 있습니다.
- 폰이 버벅이면 ☰ → 설정 → HUD → **그래픽 해상도**를 1.0 이하로 낮추세요.
- 캐릭터 보이스는 기기의 한국어 음성(안드로이드 Google, 아이폰 Yuna, 엣지 SunHi/InJoon)을 씁니다. 실제 녹음 음성은 `public/voice/README.md` 참고.

## 실행
```
node server.js
```
- PC: http://localhost:5173
- 폰: 같은 Wi-Fi에서 콘솔에 표시되는 `http://192.168.x.x:5173` 접속 → 가로 모드

## 배포 (Cloudflare Pages + GitHub)
빌드 과정 없는 정적 사이트입니다. Cloudflare 대시보드 → Workers & Pages → Pages → Git 저장소 연결 후:
- 프레임워크 프리셋: **None**
- 빌드 명령: **(비워둠)**
- 빌드 출력 디렉터리: **public**

게임 파일은 모두 `public/` 안에 있고, `server.js`·`package.json`은 로컬 개발용입니다.
`main` 브랜치에 push하면 자동 배포되고, 다른 브랜치는 미리보기 URL이 생깁니다.

## 맵 "컨테이너 야드" 설계 기준
- 거울 대칭(z=0 기준)이라 양 팀 조건이 같습니다.
- 엄폐물 높이: **낮음 1.05m**(서서 쏠 수 있음 / 앉으면 숨음), **높음 2.2m**(완전 은폐, 옆으로 피킹), **벽 3.5m**.
- 스폰 안쪽에서 적 진영 절반이 보이는 시야선이 없도록 맞췄습니다 (맵 분석 화면으로 확인).
- 구역별 최장 시야(서서): 저격 라인 76m · 중앙 63m · 창고 59m(스폰 쪽 입구 방) · 우회 골목 40m.

## 캐릭터 밸런스 기준
| 캐릭터 | 클래스 | 속도 | 체력 | 판정 면적 | 생존력 | 패시브 |
|---|---|---|---|---|---|---|
| 레오 | 돌격병 | ×1.00 | 100 | 100% | 100 | 재장전 15% 빠름 |
| 미나 | 정찰병 | ×1.10 | 80 | 89% | 90 | 정조준 전환 20% 빠름 |
| 스파크 | 기동병 | ×1.04 | 90 | 93% | 96 | 앉은 상태 이동 +60% |
| 유키 | 저격병 | ×0.96 | 95 | 88% | 108 | 정조준 이동 탄퍼짐 40% 감소 |
| 브루노 | 중화기병 | ×0.90 | 125 | 108% | 115 | 반동 15% 감소 |

- 생존력 지수 = 체력 ÷ 판정 면적 (레오 = 100). 목표 ≈ 100 − (속도 − 1) × 150 → 빠를수록 낮게.
- 보이는 모델과 피격 판정은 분리돼 있고, 판정 배율로 체형 차이를 줄입니다 (브루노 0.9, 미나 1.04).
- 체력은 AR 몸통 필요 탄수 구간이 크게 벌어지지 않게 반올림했습니다 (미나 80 = 4발, 브루노 125 = 5발).

## 게임 모드
| 모드 | 무기 | 시간 | 목표 | 리스폰 | 무적 | 특징 |
|---|---|---|---|---|---|---|
| 훈련장 | 전체 | - | - | - | - | 움직이는 표적, 맵 순간이동 |
| 팀 데스매치 | 전체 | 5분 | 40킬 | 3초 | 1.5초 | 4대4 기본 모드 |
| 저격전 | 저격소총 · 칼 | 4분 | 30킬 | 3초 | 2초 | 긴 무적으로 스폰 저격 방지 |
| 칼전 | 칼 | 3분 | 25킬 | 2초 | 1.5초 | 베기 50 / 찌르기 100, 등 뒤 2배, 이동 ×1.1 |
| 칼칼전 | 칼 | 2분 30초 | 30킬 | 1초 | 1초 | 모든 공격 한 방, 이동 ×1.3 |

- 리스폰 무적 중에는 피해를 받지 않고, 공격하면 무적이 즉시 풀립니다 (스폰 킬 악용 방지, 끌 수 있음).
- 스폰은 살아 있는 적에게서 가장 먼 지점을 고릅니다.
- 모드별 시간·목표 킬·리스폰·무적과 AI 난이도는 모드 선택 화면에서 바꾸고 저장됩니다.
- AI: 시야(정면 150°·벽 판정) → 반응 시간 → 조준 오차가 점점 줄어드는 조준 → 끊어 쏘기, 교전 중 좌우 무빙, 맞으면 돌아봄.

## 사운드 설계 (사플)
- 모든 월드 소리는 3D 위치를 가집니다 (HRTF, 이어폰 권장). 벽 너머 소리는 먹먹하게, 먼 총성은 고음이 깎이고 소리 속도만큼 늦게 도착합니다.
- 발소리: 적 ×1.5 / 아군 ×0.45 / 나 ×0.25 (튜닝에서 조절). 바닥 재질별 소리 — 모래(중앙·스폰), 자갈(저격 라인), 나무(우회 골목), 철판(창고).
- **앉아서 걸으면 발소리가 나지 않고 AI도 듣지 못합니다.** 걷는 발소리(16m)와 총성(45m)은 적 AI가 듣고 확인하러 옵니다.
- 총성 4겹: 총구 클릭 · 몸통 노이즈 · 저음 펀치 · 잔향 + 탄피(AR/SMG/권총) · 노리쇠(SR) · 펌프(SG). 재장전은 탄창 분리 → 결합 → (빈 탄창) 노리쇠.
- 보이스: 재장전 "탄창 교체!", 적 발견 "적 발견!", 처치/헤드샷, 체력 위험, 아군 사망, 부활, 아나운서(작전 개시·10초·더블/트리플 킬·승패). "폭탄 설치 완료!"는 폭파 미션용으로 미리 준비.

## HUD 편집 (⚙ 튜닝 → 🖐 HUD 편집)
| 프리셋 | 손 | 특징 |
|---|---|---|
| 2핑거 | 양손 엄지 | 큰 발사 버튼을 누른 채 회전, 적 위에서 자동 사격 |
| 3핑거 | + 왼손 검지 | 왼쪽 위 발사 버튼, 엄지는 이동·회전 |

## 육성 · 경제 설계
**원칙: 등급·강화·파츠는 데미지를 올리지 않습니다.** 데미지 +4%만 돼도 AR이 미나(체력 80)를 4발 → 3발에 처치해 처치 탄수 구간이 깨지기 때문입니다. 성장은 편의 성능 · 파츠 슬롯 · 외형으로 줍니다.

| 항목 | 내용 |
|---|---|
| 무기 등급 | 일반(총구·탄창) → 희귀(+개머리판, 파란색) → 전설(파츠 효과 +20%, 금색 발광) |
| 강화 | 등급마다 +0~+5, 단계당 반동 -2% · 장전 -1.5%. 비용 🪙200×단계×(1/2/4) |

| 파츠 슬롯 | 총구(소음기·보정기·소염기) · 탄창(대용량·빠른 교체) · 개머리판(전술·중량) |
| 파츠 등급 | 효과 배율 일반 1.0 / 희귀 1.3 / 전설 1.6. 대부분 장단점이 함께 있음 (예: 대용량 탄창 = 탄창↑ 장전↓) |
